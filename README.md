# Jer-RegionScanner-Ingame
This is a MCreator workspace for my mod JerRegionScannerIngame, created for the modloader Forge or NeoForge (pay attention to the respective file name!).

## Important
This workspace was created with MCreator 2024.2 and is intended for the following modloader versions:

- **Forge 1.20.1**
- **NeoForge 1.20.6**

⚠️ Note on compatibility with MCreator versions:

If you want to open the workspace in a newer MCreator version (e.g. 2024.4), you must update it.
Please note: From version 2024.4, Forge is no longer supported, MCreator will then rely exclusively on NeoForge.

### Compatibility rules:
- Workspace from 2024.2 → 2024.4 = ✅ possible (with switch to NeoForge)
- Workspace from 2024.4 → 2024.2 = ❌ not possible

When opening a workspace with an older MCreator version, a warning appears that it was created with a newer version.
👉 Make sure to create a backup beforehand!

#### For plugins and NeoForge from 1.21.1

As of NeoForge version 1.21.1, MCreator automatically informs you if additional plugins are required to run the workspace correctly.
These plugins work similarly to mod dependencies in Minecraft and must be installed separately for everything to run smoothly.
